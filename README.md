# RK3568 KXB LP4 V10 Armbian Port

## Overview

This repository contains the work required to boot Linux Mainline and Armbian on the Rockchip RK3568 KXB LP4 V10 board.

Current hardware:

| Item | Value |
|------|-------|
| SoC | Rockchip RK3568 |
| CPU | Cortex-A55 Quad Core |
| RAM | 4 GB LPDDR4 |
| Storage | 16 GB eMMC |
| Ethernet | Gigabit Ethernet |
| UART | CH340 Debug |
| Target OS | Debian 12 Bookworm |
| Distribution | Armbian |

---

## Project Goals

- Boot Linux Mainline
- Boot Armbian CLI
- Boot Armbian XFCE
- HDMI Output
- Gigabit Ethernet
- USB Host
- eMMC Support
- WiFi
- Bluetooth
- GPU
